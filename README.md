# Навык Алисы: Gemini + интернет-поиск

Стартовая версия для Vercel. Для каждого вопроса получает три результата Serper, передаёт выдержки в Gemini и возвращает краткий ответ и кнопки источников. Это поиск по выдаче, а не чтение полных страниц. Без сторонних библиотек.

## Статус

Локальные проверки используют имитацию API. Реальная скорость, доступность ключей и работа на колонке должны быть проверены после развёртывания. Проект ещё не опубликован и не запущен.

## Настройка

1. Создайте Gemini API-ключ в https://aistudio.google.com/api-keys и Serper API-ключ в https://serper.dev. Проверьте доступность услуг для своего аккаунта и страны, квоты и оплату.
2. Загрузите содержимое этой папки в репозиторий GitHub. Не загружайте `.env.local` и настоящие ключи. Импортируйте репозиторий в Vercel; Framework Preset — Other, без команды сборки.
3. Создайте черновик навыка в https://dialogs.yandex.ru/developer и скопируйте его ID.
4. Добавьте переменные Vercel для Production: `GEMINI_API_KEY`, `SERPER_API_KEY`, `ALICE_SKILL_ID`, `WEBHOOK_SECRET`. Для секрета используйте случайные 32 байта (64 hex-символа), например `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`. `GEMINI_MODEL` по умолчанию — `gemini-3.8-flash`; доступность проверяется вашим аккаунтом.
5. Выполните новое production-развёртывание. В навыке установите webhook `https://ВАШ-ДОМЕН/api/alice?token=ВАШ-СЕКРЕТ`. Используйте постоянный production-домен. Внешние запросы Яндекс Диалогов должны иметь доступ к webhook без страницы входа Vercel; не отключайте защиту других проектов.
6. Проверьте `/api/health`: `configured` подтверждает наличие настроек, но не работоспособность API.
7. В тестере Диалогов проверьте приветствие, общий вопрос, вопрос о свежем событии, уточняющий вопрос и «выход». На колонке проверьте несколько вопросов подряд и первый запрос после простоя.
8. Публикация для всех — отдельный этап с заполнением описания, иконки, необходимых сведений о данных и модерацией Яндекса.

## Ограничение скорости

Яндекс ждёт весь ответ только 4,5 секунды: https://yandex.ru/dev/dialogs/alice/doc/ru/response. Обработчик отменяет внешние запросы через 3,3 секунды, оставляя время на сеть. Это не гарантирует укладывание при холодном запуске или медленной сети. Если реальные проверки показывают частые таймауты, следующий этап — фоновая задача с постоянным хранилищем и получение результата следующей репликой. В текущей версии нет фонового продолжения и повторной выдачи готового результата.

## Диагностика

Логи содержат этап (`serper` / `gemini`), код и длительность, без ключей и текста вопросов. 401/403 — ключ или доступ; 404 — модель; 429 — квота или частота; timeout — время ответа. Сообщение `not_configured` — недостающие настройки. Секрет webhook в URL следует скрывать в скриншотах и журналах доступа. Проверка ID навыка сама по себе не удостоверяет Яндекс; доступ защищает секрет URL. Для массовой публикации нужны распределённое ограничение запросов и бюджетные лимиты сервисов; в текущей версии они не реализованы.

## Данные

Вопрос и иногда предыдущий вопрос отправляются Serper. Текущий вопрос, до четырёх кратких сообщений контекста и поисковые выдержки отправляются Google. Контекст хранится в состоянии сессии Яндекс Диалогов, без собственной базы. Пользователям следует сообщить о передаче данных и не предлагать отправлять секреты.

## Локальный запуск

Node.js 24. Скопируйте `.env.example` в `.env.local`, заполните значения, выполните `npm test`, затем `npm start`. Сервер доступен только на `127.0.0.1:3000`. Для публикации используйте Vercel.
